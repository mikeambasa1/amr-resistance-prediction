# Predicting Antibiotic Resistance in Klebsiella pneumoniae from Genomic Data

## Objective
Predict resistance phenotypes from AMR gene presence/absence and build a
surveillance dashboard.

## Scope
- Species: Klebsiella pneumoniae
- Antibiotics: ciprofloxacin, ceftriaxone, gentamicin
- Target sample size: 500-1,000 genomes with lab-measured AST data
- Tools: AMRFinderPlus, Python (pandas, scikit-learn), Streamlit
